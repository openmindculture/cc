# Requirements Prof. CC. Website

A new website in a classic design for a university professor to showcase his books, publications and possibly other content like blog posts, podcast episodes, videos. Content management using WordPress.

A timelessly minimalist design and technology should adhere to classic values so that the website is ideally still usable and will not look outdated in ten years from now, when still using the 2026 theme in 2036.

Important:
- accessibility (WCAG A)
- web performance (load time optimization)
- SEO + GEO on-page marketing optimization

To stay within a budget, and to minimize the learning curve both for the professor using the CMS, and for the web developer, we want to use WordPress core built-in features, WordPress standards, web standards, and established design and publishing standards.

Technically, a twentytwentyfive-child block theme with optional classic parts, and optional custom-coded custom post types is possible. The web developer is experienced in frontend and backend, and familiar with PHP code.

## Content types:

- post
- book
- publication
- media, if not page or post matches best
